# Democracy Routes Workflow Editor

## Local development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server (SQLite + API + static hosting):
   ```bash
   npm start
   ```
3. Open the app in your browser:
   ```
   http://localhost:3004
   ```

The server persists modules and workflows in SQLite at `db/democracy_routes.db`.
